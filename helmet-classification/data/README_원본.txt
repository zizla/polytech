안전모 착용 여부 이미지 데이터셋 (가상, 교육용)
=================================================
- 파이썬(make_helmet_images.py, 난수 씨앗 2026)으로 그린 합성 이미지입니다. 실제 현장 사진이 아닙니다.
- train/안전모착용, train/안전모미착용 : 클래스별 120장, 299×299 JPEG (Inception v3 입력 크기)
- new/ : 정답을 숨긴 예측 실습용 15장 (정답은 별도 파일 '정답_helmet_new.csv' — 수강생 배포 전 분리 보관)
- labels.csv : train 이미지의 클래스와 '머리상태'(안전모 색, 모자 종류, 손에 든 물건)

미착용 클래스 구성 (train 120장): 맨머리 약 50%, 야구모자 약 25%, 비니 약 15%, 후드 약 10%
  · 그중 25장은 안전모를 손에 들고 있음(쓰지 않았으므로 미착용)
  · 야구모자·비니는 안전모와 같은 색 목록에서 색을 고름 → 색만으로는 구분되지 않게 함
클래스와 무관하게 무작위인 요소: 배경(하늘·지면·건물·비계·크레인·라바콘), 조명, 피부색, 머리색, 옷·형광조끼,
  보안경, 서류판·무전기, 사람 위치·크기·기울기, 흐림

점검 결과 (train 240장, 5겹 교차검증):
  · 배경 모서리 색만으로 분류 → 47% (무작위 수준 50%) : 배경이 정답 단서가 아님
  · 이미지 전체 색 분포로 분류 → 58% : 색만으로는 거의 못 맞힘 → 모양을 보는 특징(Inception 임베딩)이 필요한 과제
  · Inception v3 임베딩으로의 정확도는 만든 쪽에서 확인하지 못함 (수업 전 확인 권장)

Orange 워크플로 (Image Analytics 애드온 필요)
1) Import Images : train 폴더 → 하위 폴더 이름이 클래스
2) Image Embedding : Inception v3 (외부 서버 사용, 인터넷 필요 / 오프라인이면 SqueezeNet)
3) Test and Score → Confusion Matrix → Image Viewer 로 틀린 이미지 확인
4) new 또는 test10 폴더 → Import Images → Image Embedding → Predictions
