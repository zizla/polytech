모듈 A. 어묵 — 평균이 원인을 숨긴다

데이터: cj_fishcake_qc · 기존 방법: 엑셀 평균·표준편차 + t-검정

① Before — 엑셀로 합격/불합격 비교표 만들기

  1. cj_fishcake_qc_excel.csv를 엑셀로 엽니다.
  2. 새 시트에 변수별로 합격·불합격 평균과 표준편차를 구합니다.
    =AVERAGEIFS(튀김온도열, 합격여부열, "Pass"), =STDEV.S(IF(합격여부열="Fail", 튀김온도열)) (엑셀 2019 이전은 Ctrl+Shift+Enter로 입력)
  3. 데이터 → 데이터 분석 → t-검정: 이분산 가정 두 집단으로 변수마다 p-값을 구합니다. (데이터 분석 메뉴가 없으면 파일 → 옵션 → 추가 기능 → 분석 도구 활성화)
  4. p < 0.05인 변수를 “불량 원인 후보”로, 나머지를 “무관”으로 분류해 결론을 한 문장으로 적습니다.

② 막힘

엑셀 결론은 “튀김 온도를 관리하면 된다. 세균수와 세척 주기는 불량과 무관하다”입니다.

그런데 미생물 기준 초과로 반품된 배치가 있습니다. 세균수가 불량과 무관하다는 결론을 품질팀장에게 그대로 보고할 수 있을까요?

원인: 불합격 배치의 대부분이 탄 자국(Burn) 불량입니다. 성격이 다른 불량을 하나의 “Fail”로 묶어 평균을 내면, 수가 적은 미생물 불량의 신호가 묻힙니다.

③ After — Orange로 다시 보기

File ─ Select Columns (Target: 불량유형) ─┬─ Box Plot (일반세균수_log, Subgroups: 불량유형) ├─ Rank └─ Tree ─ Tree Viewer
  1. Select Columns에서 타깃을 불량유형으로 바꿉니다(합격여부는 Ignore).
  2. Box Plot에서 일반세균수_log를 불량유형별로 보십시오. 미생물 불량 배치의 평균은 3.40, 합격 배치는 2.65입니다(t-검정 p<0.001).
  3. Rank 위젯으로 불량유형별 중요 변수를 보고, Tree Viewer에서 Microbial로 가는 경로를 읽으십시오.
  4. Box Plot에서 근무조, 세척후경과시간과 미생물 불량의 관계를 확인합니다. 미생물 불량률은 Night 4.4% / Day 1.6%, 세척 후 6시간 초과 4.3% / 이하 1.0%입니다.

  1. 연속 변수 4개로 k=2~6을 비교해 실루엣 점수가 가장 높은 k를 고르고, 군집별 불량률과 업체 구성을 해석합니다.
  2. 공통 변수만 남긴 통합 데이터의 AUC를 업체별 데이터와 비교합니다(scikit-learn 기준 통합 RF 0.626 vs 업체별 0.80~0.87).

짚을 점: 데이터를 많이 모으는 것보다 공정을 설명하는 변수를 기록하는 것이 중요합니다. 물류센터 입지 k-means와 같은 “군집 → 해석 → 검증” 흐름이지만, 군집이 불량 라벨과 일치해야 할 이유는 없습니다.

설계된 생성 규칙 요약 — 불량 확률은 아래 변수의 로지스틱 함수로 만들었습니다. 불량유형이 겹치면 Burn/Tear/Weak_Intensity/Low_Brix가 우선합니다.

  • 어묵 Burn: 튀김온도↑, 튀김시간↑ · Microbial: 일반세균수_log↑ (이 값은 중심온도↓, Night 근무조, 세척후경과시간↑의 영향) · Soft_Texture: 겔강도↓ (어육배합비↓, 전분배합비↑의 영향). 센서 이상치: CJ-0006(201.5), CJ-0117(198.0), CJ-0150(121.0).
  • 조미김 Tear: 원초 등급 C쪽, 원초중량↓, 구이온도↑ · Pinhole: 핀홀수↑ · Moisture_Absorption: 수분활성도↑ (작업장습도의 영향).
  • 향료 Seal_Defect: 캡토크가 15에서 양방향으로 멀어질수록↑(U자형) · Underfill: 충전량편차↓ · Weak_Intensity: 향강도↓. 점도·굴절률 결측 190건은 모두 Powder.
  • 도라지 Low_Brix: 제품유형별 규격(Syrup 65, TeaBase 45, Drink 12 °Brix) 대비 당도_Brix가 낮을수록↑ · Browning: 갈변도_A420↑(농축온도·농축시간이 함께 높을 때 더 커짐) · Microbial: 일반세균수_log↑(충전온도↓, 세척후경과시간↑의 영향) · Low_Saponin: 조사포닌_mg_g↓(원료산지 Imported에서 낮음, 추출시간·온도의 영향). Low_Saponin 비율은 Imported 19.0%, Domestic_B 1.1%, Domestic_A 0%.

실험 시뮬레이터(모듈 B) — 생산 데이터와 같은 갈변 생성식을 씁니다: 갈변도 = 0.35 + 0.05×[(T−85)/4 + (t−60)/10] + 0.06×max(T−88,0)×max(t−65,0)/10 + 오차(SD 0.04), 갈변 확률 = logistic(−3.4 + 30×(갈변도−0.45)). 기준 85°C·60분에서 한 요인만 바꾸면 갈변 확률은 대체로 수 %~10%대에 머물고, 두 요인을 함께 올리면(예: 92°C·80분) 거의 모든 배치가 갈변합니다. 학생이 이 조합을 시도하지 않도록 유도하지 말고, 예산 안에서 자연스럽게 고르게 두십시오.

관능 패널 — 검사원 점수 = 기준향강도 + 편향 + 오차. 편향: 검사원2 +0.6, 검사원3 −0.4. 오차 SD: 0.3/0.4/0.5/0.3(검사원4는 평가순서에 따라 최대 +1.2 증가)/0.9.

Formula의 조건식(... if ... else ...)과 한글 변수명 계산이 Orange에서 동작하는지 수업 전에 확인하십시오. 안 되면 Select Rows로 제품별로 나눠 각각 계산합니다.
