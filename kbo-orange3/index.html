3. 군집분석 워크플로

File → Select Columns → Preprocess → k-Means ─┬→ Scatter Plot ├→ Data Table └→ Box Plot

열 고르기 (Select Columns)

  • 특징(Features): 수치형 지표만 넣습니다. 예) 타자 — AVG, HR, RBI, R, H, TB, PA / 투수 — ERA, WHIP, IP, SO, W, SV, HLD
  • 메타(Meta)로 보낼 열: 선수명, 팀명, year — 이름은 결과 라벨로만 쓰고 거리 계산에는 넣지 않습니다. year는 전부 2025라 값이 하나뿐이므로 특징에서 빼야 합니다.
  • 타깃(Target): 지도학습이 아니므로 비워 둡니다.

정규화 (Preprocess)

  • 타율(0.2~0.4)과 타점·루타수(수십~수백)는 단위가 달라, Normalize(평균 0·표준편차 1)를 먼저 적용합니다. 정규화 없이 k-Means를 돌리면 스케일이 큰 열이 거리를 독점합니다.

군집화 (k-Means)

  • k 값을 2 → 3 → 4로 바꿔 가며 실루엣 점수와 산점도를 비교합니다.
  • "타격형 / 장타형 / 수비·주루형" 같은 해석은 Data Table에서 클러스터별 선수 명단을 눈으로 확인한 뒤 붙입니다.

결과 해석 (Scatter Plot · Box Plot)

  • Scatter Plot: x·y에 대표 지표 2개(예: AVG–HR)를 넣고 Color를 Cluster로 지정합니다.
  • Box Plot: Variables에 지표를 넣고 Subgroups를 Cluster로 두면 클러스터 간 분포 차이가 한눈에 보입니다.
해석 주의 — 군집은 "정답 분류"가 아니라 데이터가 만든 묶음입니다. k 값과 투입 지표를 바꾸면 결과가 달라지므로, 결론은 "어떤 지표 조합에서 어떤 묶음이 안정적으로 나오는가"로 서술합니다.
타자 데이터는 규정타석 미달(PA<100) 선수를, 투수 데이터는 소화 이닝 미달(IP<30) 선수를 제외했습니다. 시즌 중 이적 선수는 소속팀 기록 기준으로 한 번만 집계됩니다.
